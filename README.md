# GreenTrust AI / CyberAbeer

Private repository for the CyberAbeer.com + GreenTrust AI project. Contains phase deliverables produced during planning and design.

## Structure

- docs/PHASE1_Product_Blueprint.docx - business objectives, sitemap, SEO/content strategy
- docs/PHASE2_Technical_Architecture.docx - stack decisions, deployment, security baseline
- docs/PHASE3_Database_Design.docx - ERD, table definitions, RLS/tenant isolation
- database/migrations/ - ordered SQL migration files 001 to 008 (extensions/core, content/leads, labs, greentrust, quantum, commerce/security, RLS policies, seed data)
